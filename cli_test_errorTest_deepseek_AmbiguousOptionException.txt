To solve this problem, we need to create a custom exception class `AmbiguousOptionException` that generates specific error messages based on the provided ambiguous option and a list of possible matching options. The error message must follow a precise format to handle various edge cases, including null values, empty strings, and strings containing apostrophes.

### Approach
1. **Message Construction**:
   - The message starts with "Ambiguous option: " followed by the provided option. If the option is `null`, it should be displayed as `null` without quotes. If it's an empty string, it should be wrapped in single quotes (`''`). Otherwise, the option is enclosed in single quotes.
   - The message includes a list of possible matching options, each enclosed in single quotes and separated by commas. This list is formatted as "(could be: 'option1', 'option2')".

2. **Handling Special Cases**:
   - **Null Option**: Directly append `null` without quotes.
   - **Empty Option**: Wrap in single quotes to indicate an empty string.
   - **Apostrophes in Options**: Enclose each option in single quotes without escaping internal apostrophes.
   - **Empty Matching Options List**: If no matching options are provided, the list part of the message ends immediately after "could be: ".

### Solution Code
```java
package cli;

import java.util.Collections;
import java.util.List;
import java.util.stream.Collectors;

public class AmbiguousOptionException extends RuntimeException {
    private final String option;
    private final List<String> matchingOptions;

    public AmbiguousOptionException(String option, List<String> matchingOptions) {
        super();
        this.option = option;
        this.matchingOptions = Collections.unmodifiableList(matchingOptions);
    }

    @Override
    public String getMessage() {
        StringBuilder message = new StringBuilder("Ambiguous option: ");
        if (option == null) {
            message.append("null");
        } else if (option.isEmpty()) {
            message.append("''");
        } else {
            message.append("'").append(option).append("'");
        }
        message.append("  (could be: ");
        if (matchingOptions.isEmpty()) {
            message.append(")");
        } else {
            String optionsList = matchingOptions.stream()
                    .map(opt -> "'" + opt + "'")
                    .collect(Collectors.joining(", "));
            message.append(optionsList).append(")");
        }
        return message.toString();
    }
}
```

### Explanation
- **Message Construction**: The `getMessage()` method constructs the error message dynamically based on the provided option and matching options. It uses a `StringBuilder` for efficient string concatenation.
- **Handling Option**: The option is checked for `null` and empty string to format appropriately without or with single quotes.
- **Matching Options**: The list of matching options is converted into a comma-separated string, each enclosed in single quotes using Java Streams for concise code.
- **Edge Cases**: The solution handles all edge cases including `null` options, empty options, and empty matching options list, ensuring the output format matches the expected test cases.

This approach ensures that the `AmbiguousOptionException` generates precise and correct error messages for various scenarios, adhering to the specified format in all test cases.over
